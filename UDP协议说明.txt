============================================================
           远程命令GUI系统 UDP协议说明文档
============================================================

【基本信息】
● 发送端口：6743
● 接收端口：6746
● 编码格式：UTF-8
● 广播地址：255.255.255.255
● 协议前缀：MOT-RC

【数据包基本格式】
MOT-RC [命令类型] [参数1] [参数2] ...

【完整命令列表】

一、基础控制命令
────────────────────────────────────
● MOT-RC runcmd
  功能：发送运行命令广播包
  模式：广播

● MOT-RC update  
  功能：发送更新命令广播包
  模式：广播

● MOT-RC link [IP地址]
  功能：发送服务器链接信息
  模式：广播/单播

二、进程管理命令
────────────────────────────────────
● MOT-RC process list
  功能：请求进程列表信息
  模式：广播/单播

● MOT-RC process app
  功能：请求应用进程列表
  模式：广播/单播

● MOT-RC process taskkill [进程名]
  功能：结束指定进程
  模式：广播/单播

三、路径黑白名单管理
────────────────────────────────────
● MOT-RC path_black add [路径列表]
  功能：添加黑名单路径
  参数格式：多个路径用逗号分隔，如"C:\Program Files\*,D:\Data\*"
  模式：广播/单播

● MOT-RC path_black del [路径列表]
  功能：删除黑名单路径
  模式：广播/单播

● MOT-RC path_white add [路径列表]
  功能：添加白名单路径
  模式：广播/单播

● MOT-RC path_white del [路径列表]
  功能：删除白名单路径
  模式：广播/单播

● MOT-RC path_mode whitelist
  功能：切换到路径白名单模式
  模式：广播/单播

● MOT-RC path_mode blacklist
  功能：切换到路径黑名单模式
  模式：广播/单播

四、程序黑白名单管理（新增）
────────────────────────────────────
● MOT-RC black add [程序列表]
  功能：添加黑名单程序
  参数格式：多个程序用逗号分隔，如"notepad.exe,calc.exe,chrome.exe"
  模式：广播/单播

● MOT-RC black del [程序列表]
  功能：删除黑名单程序
  模式：广播/单播

● MOT-RC width add [程序列表]
  功能：添加白名单程序
  模式：广播/单播

● MOT-RC width del [程序列表]
  功能：删除白名单程序
  模式：广播/单播

● MOT-RC mode whitelist
  功能：切换到程序白名单模式
  模式：广播/单播

● MOT-RC mode blacklist
  功能：切换到程序黑名单模式
  模式：广播/单播

五、系统配置命令
────────────────────────────────────
● MOT-RC restore_config
  功能：还原所有配置
  模式：广播/单播

● MOT-RC disable_nic_detection
  功能：关闭网卡检测功能
  模式：广播/单播

● MOT-RC disable_all_features
  功能：关闭所有功能
  模式：广播/单播

六、通用命令执行
────────────────────────────────────
● MOT-RC cmd [具体命令]
  功能：执行任意CMD命令
  示例：MOT-RC cmd shutdown /r /t 5 （一键重启）
  模式：广播/单播

七、客户端日志回传格式
────────────────────────────────────
● MOT-RC cmdlog [日志内容]
  功能：客户端回传普通日志信息

● MOT-RC process pl app:"应用进程" bg:"后台进程"
  功能：回传进程列表信息

● MOT-RC process apl:"路径+名称,路径+名称"
  功能：回传详细应用进程信息

【通信模式说明】

1. 广播模式（Broadcast）
   ● 目标地址：255.255.255.255:6743
   ● 向所有网络接口发送
   ● 适用于群发命令到多台设备

2. 单播模式（Unicast）
   ● 目标地址：具体IP地址:6743
   ● 向指定设备发送
   ● 适用于精确控制特定设备

【参数格式规范】

● 路径列表：多个路径用英文逗号分隔
  示例："C:\Windows\*,D:\Program Files\*,E:\Data\*"

● 程序列表：多个程序名用英文逗号分隔
  示例："notepad.exe,calc.exe,chrome.exe,firefox.exe"

● IP地址：标准IPv4格式
  示例："192.168.1.100"、"10.0.0.50"

【实际应用场景】

1. 批量设备管理
   - 通过广播同时向多台设备发送控制命令
   - 统一配置管理策略

2. 精细化控制
   - 通过单播精确控制特定设备
   - 针对性的问题处理

3. 安全防护
   - 通过黑白名单机制限制程序和路径访问
   - 实现细粒度的安全管控

4. 系统维护
   - 远程执行系统命令和进程管理
   - 自动化运维操作

5. 状态监控
   - 实时收集设备运行状态
   - 集中化的日志信息管理

【注意事项】

1. 所有命令均以"MOT-RC"开头作为协议标识
2. 参数中包含空格时建议使用引号包围
3. 路径和程序名区分大小写
4. 支持一次添加多个路径或程序（用逗号分隔）
5. 可选择广播或指定IP地址发送命令
